What does "Hinglish" mean here?

Hindi speech written in English letters — like "mujhe kal meeting hai" instead of "मुझे कल मीटिंग है".

How long does it take?

Roughly a few minutes for a 10-minute clip. Longer files take longer — you can leave the tab open; we'll show the result the moment it's finished.

Which file shows one word at a time?

The word-by-word .srt. Every word has its own start and end time, so apps that highlight or show the current word will work with it.
